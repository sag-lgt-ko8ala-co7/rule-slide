# ルール説明スライド

ボードゲームのルールを入力すると、自動でスライドになり、全画面で順番に説明できるWebアプリです。
説明書を読み上げても伝わらない「説明係」のために作りました。

![スクリーンショット](docs/screenshot.png)

## 公開URL
https://rule-slide.vercel.app

## できること
- ゲームの基本情報（人数・時間・対象・概要・勝利条件）とルール項目を登録
- 入力内容から自動でスライドを作成
- 発表モードで全画面表示し、タップや矢印キーで説明
- 登録したゲームの一覧・編集・削除

## 技術スタック
| 分類 | 使用技術 |
| --- | --- |
| フレームワーク | Next.js（App Router） |
| 言語 | TypeScript |
| スタイル | Tailwind CSS |
| データ保存 | localStorage（ブラウザ内） |
| デプロイ | Vercel |
| 開発 | Claude Code（Plan Mode、CLAUDE.md） |

## ローカルでの起動
```bash
npm install
npm run dev
```

## 注意
- データは使っているブラウザの中にだけ保存されます。別の端末やブラウザでは見えません
- サンプルのゲームは自作です。市販ゲームの説明書は転載していません
